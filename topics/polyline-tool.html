Polyline Tool

The Polyline tool lets you draw shapes made of multiple connected line segments. It's perfect for creating custom shapes, diagrams, technical drawings, or any path that needs precise control over individual points.

Basic Usage

  1. Select the Polyline tool from the toolbar or choose Tool > Polyline.
  2. Click on the canvas to place the first point.
  3. Move your pointer and click to add more points. The last segment follows your cursor as a preview.
  4. To finish the polyline:
    • Double-click anywhere on the canvas
    • Right-click anywhere on the canvas
    • Press Esc to discard the entire polyline

Tips

While drawing, each new point creates a straight segment from the previous point. The shape remains editable after completion.

Creating Curved Segments

You can mix straight and curved segments in the same polyline:

  • Hold Option (⌥) while clicking to add a point to create a curved segment instead of a straight one
  • The curve is created with smooth direction handles that you can adjust later

Angle Constraints

Hold Shift while adding a point to constrain the last segment to:

  • Horizontal (0°)
  • Vertical (90°)
  • 45-degree angles (45°, 135°, etc.)

This helps you create precise geometric shapes and maintain clean angles in your drawings.

Editing After Completion

Once you finish drawing, the polyline becomes an editable object:

Adjust Individual Points

  • Drag any control knob at a point (square for corner points, round for curve control points) to reposition it
  • The connected segments update automatically

Reshape the Entire Polyline

  • Use the Select and Move Tool to select the entire polyline
  • Drag to move it, or use the transform handles to resize/rotate

Modify Segment Properties

With the polyline selected, you can adjust:

  • Line — a color, a gradient, or a pattern — and its thickness in the Attributes panel
  • Shadow, reflection, and other effects

Tips

An open polyline can't be filled. To fill it, select it, right-click, and choose Close Path: the polyline becomes a closed polygon with a Fill option — a color, a gradient, or a pattern.

Practical Examples

Drawing a Simple Arrow

  1. Click to place the arrow tail
  2. Click to place the shaft endpoint
  3. Click twice more to create the arrowhead wings
  4. Double-click to finish
  5. Adjust point positions by dragging the knobs

Creating a Custom Diagram

  1. Start with key anchor points for your diagram structure
  2. Add intermediate points for detail
  3. Use Shift to keep important lines horizontal or vertical
  4. Finish and adjust individual points for precision

Making an Irregular Shape

  1. Outline the general shape with several points
  2. Hold Option on some points to add curves where needed
  3. Bring the last point back to the first point, then double-click to finish
  4. Right-click the shape and choose Close Path, then apply a fill — a color, a gradient, or a pattern — to complete it

Tips and Tricks

  • Start simple: Begin with fewer points, then add more by editing later
  • Use constraints: Hold Shift frequently to maintain clean geometry
  • Mix techniques: Combine the Polyline tool with other shape tools for complex compositions
  • Close for a fill: Bring the last point back to the first one, then use Close Path to turn the polyline into a fillable polygon
  • Start over if needed: Points can't be undone one by one while drawing; press Esc to discard the polyline and start again

Related Tools

  • Vector Pen Tool — For more advanced path creation with Bézier curves
  • Curve Tool — For simple two-point curves
  • Transform Objects — For resizing and rotating completed polylines
