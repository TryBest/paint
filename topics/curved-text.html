Curved Text

Add Curved Text

You can add curved text in two ways:

1. Add Directly to the Canvas

  1. Choose Object > Add Curved Text… from the menu bar.
  2. In the dialog, select a path shape and click OK.
  3. Type your text.
  4. Press the Esc key to finish typing.
  5. Drag the control knobs to adjust the curve.

2. Add to an Existing Shape or Path

  1. Select an existing shape or path on the canvas.

Tips

You can draw a custom path using the Curve, Polyline, Ellipse, or Pen tool first. You can hide or delete the original path later if you only want the text to be visible.

  1. Choose Object > Add Curved Text to Current Object.
  2. Type your text.
  3. Press the Esc key to finish typing.
  4. Adjust the path or shape as needed.

Adjust the Curve

Select the curved text object and drag its control knobs on the canvas to reshape the curve.

Edit the Text

To modify the text content, select the object with the Select and Move Tool, then double-click it or press Return.

To finish editing, press Esc or right-click the canvas and choose End Editing.
