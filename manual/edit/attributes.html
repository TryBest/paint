Modify Attributes

You can adjust the properties of tools and selected objects using the Attributes Panel, located just below the toolbar.

Info

The panel follows your selection. When you select an object, the panel switches to show the rows that object supports — not the rows of the tool you drew it with. Selecting a Fill object shows only Fill; selecting a text object adds the whole text row set. The available options therefore vary depending on the selected tool or object.

Most attribute rows have two kinds of controls: a checkbox that turns the attribute on or off, and a button or pop-up that reveals its details (for example, the color, gradient, or pattern).

Position

Drag selected objects on the canvas to move them. For precise adjustments, use the arrow keys on your keyboard: each press nudges the object by 1 pixel, and holding Shift or Command gives you half-pixel steps. With nothing selected, the same arrow keys scroll the canvas instead.

With the Rectangular Selection, Elliptical Selection, or Crop tool active, the panel also shows a Position and Size row where you can type exact Left, Top, Width, and Height values in pixels. The Lasso and Polygon Selection tools do not show this row.

Line and Border

Adjust the stroke properties of lines and shapes. Tick the Line checkbox first (shown as Border for closed shapes) to enable the stroke; while it is off, the other controls on this row are disabled.

  • Dash Style: Choose a solid or dashed line pattern. The menu also lets you create a custom pattern with Add Dashed Line Style…, and edit or delete your custom styles there.
  • Line Type: Choose between a solid color, a gradient, or a pattern. Selecting Gradient opens the Gradient Editor and selecting Pattern opens the Pattern panel, both immediately. A pattern well can be clicked again to bring the panel back.
  • Color/Gradient/Pattern: Set the stroke color, gradient, or pattern. See Choose a Color, Choose a Gradient, and Pattern.
  • Width: Set the line thickness in pixels.
  • Arrow Style: Add arrowheads to the end of a line, or to both ends.
  • Line Cap: Define the shape of the line endpoints (e.g., butt, round, square).

Tips

  • The row is labeled Line or Border by tool, not by shape. Line, Curve, Polyline, an open Vector Pen path, Pen, Airbrush, and Eyedropper show Line; everything else — including text boxes and images — shows Border.
  • Width accepts whole numbers from 1 to 1000, and the default is scaled to your display (2 points on a standard display, 4 on Retina). Zoom level never changes the stored value, and neither does the document's resolution.
  • Dash lengths are multiples of the line width, not fixed pixel lengths. A 3:3 dash at width 4 draws 12 points on, 12 off — and if you change the width afterwards, the dash pattern rescales to match.
  • You can save your own dash patterns (digits and colons only), up to 20 of them.

Info

The Gradient and Pattern choices are greyed out for the Pen and Airbrush, and Gradient objects have no stroke at all.

Outline

Add an outer stroke to lines, curves, and paths:

  • Enable/Disable: Toggle the outline on or off. You can turn this on only when the line (Border) attribute is enabled.
  • Width: Set the outline thickness in pixels.
  • Color: Set the outline color.

Tips

If you enable the outline and set the main line color to transparent, you will create a hollow line.

Warning

  • Only Line, Curve, Polyline, and open Vector Pen paths support an outline. Closed Vector Pen paths do not.
  • The width is limited to 1–99, and the number you type is the half-thickness of the visible outline.
  • Closing a Vector Pen path silently removes its outline, outline color, and arrowheads. Set those up after you close the path.
  • Turning the main Line/Border off also disables the outline, even if its checkbox is still ticked.

Fill

Adjust the interior color of shapes:

  • Enable/Disable: Toggle the fill on or off. For text, the fill paints a background behind the characters.
  • Fill Type: Choose between a solid color, a gradient, or a pattern. Selecting Gradient opens the Gradient Editor and selecting Pattern opens the Pattern panel, both immediately. A pattern well can be clicked again to bring the panel back.
  • Color/Gradient/Pattern: Set the fill color, gradient, or pattern.

Tips

Single-color vector icons from the content library are tinted with your current fill color. Select the inserted icon and change the color or apply a gradient here to recolor it.

Tips

Color, Gradient, and Pattern are mutually exclusive — picking one clears the other two. A single object cannot be filled with a gradient and a pattern at the same time, but gradient (or pattern) fills work independently for the stroke and for the text, so a shape can carry a gradient border and a pattern body at once.

Smooth (Anti-aliasing)

Enabled by default, this applies anti-aliasing to smooth the edges of lines, borders, and text. It is recommended to keep this enabled for better visual quality.

Tips

  • Turn this off for crisp, hard edges — it is what makes pixel art look sharp with the square Pen shape.
  • This setting is remembered between launches for shapes and lines. The Pen is the exception: its Smooth checkbox resets to On every time you launch the app.
  • Smooth is unavailable on images and the Airbrush, which always render a fixed way.

Corner Radius

Available for rounded rectangles, and also offered for images and text boxes. Adjust the curvature of the corners:

  • X: Horizontal radius (in pixels).
  • Y: Vertical radius (in pixels).

The default radius for a new round rectangle is 20 pixels (on standard displays; on high-resolution displays the stored value scales with the screen). The radius is remembered per shape type, so a round rectangle you adjusted earlier reopens with that same radius.

Tips

The row is active only while a stroke or fill is on. It appears for new text boxes and images too, but those start at 0 — only rounded rectangles pick up a remembered default.

Text

Format text objects with the following options:

  • Font: Choose the font family. Click the font button to open the Font Library, which lists the fonts installed on your Mac together with the 200+ built-in fonts that Paint S ships.
  • Font Style: Choose a specific face within that family, such as Regular or Bold Italic.
  • Size: Set the font size in pixels.
  • Fill Type: Choose between a solid color, a gradient, or a pattern for the characters. Selecting Pattern turns the well to its right into a pattern well: click it to choose the tile, then set its scale, opacity, angle, and phase. See Pattern.
  • Color/Gradient/Pattern: Set the text color, gradient, or pattern. When Fill Type is Pattern, this well becomes a pattern well—see Pattern.
  • Style: Toggle Bold, Italic, Underline, and Strikethrough.
  • Alignment: Align text to the left, center, right, or justify.
  • Spacing: Adjust the line spacing (a line-height multiplier; the menu offers presets from 0.5 to 3.0, and Show More... lets you enter a custom value).
  • Text Outline: Tick the outline checkbox to draw a stroke around the characters, then pick the outline color in the color well on the row. Click the outline settings button (the letter O) to choose the outline type—filled characters with a stroke, or hollow outline-only characters—and to set the outline width.

  • Auto Resize: When enabled, the text box automatically adjusts its size to fit the content. When disabled, the text box size is fixed, and you can resize it manually.

Tips

Text boxes also support standard Border and Fill attributes, allowing you to add a background color or frame to your text. All three of these rows — the characters, the background, and the border — accept a pattern, so a text object can be tiled with an image in up to three places at once.

Tips

  • The Size is in canvas pixels and is not affected by the document's resolution — changing the resolution in Image > Resize Canvas… does not rescale your text. The dropdown offers common sizes from 9 to 288, plus your recent choices, and you can type any value of 1 or more.
  • The outline width ranges from 0.1 to 10, but only values between 1 and 5 are remembered across launches.
  • Spacing is a line-height multiplier only, despite the tooltip's wording; it does not add space between paragraphs.

Font Library

Click the Font button to open the Font Library, a single browser over the 200+ fonts built into Paint S, the fonts installed on your Mac, and the fonts you import. Clicking a font applies it right away and closes the library. For sections, favorites, search, and importing TTF or OTF fonts, see Font Library.

Shadow

Tick the shadow checkbox to apply a shadow to the selected object, and click the Shadow button to open (or close) the detailed Shadow panel.

In the panel you can enable the standard Shadow and the Inner Shadow independently. Each has its own settings:

  • Color: Pick the shadow color. Use the color picker's opacity slider for a translucent shadow.
  • Blur: The softness of the shadow edge.
  • Offset X / Offset Y: The displacement of the shadow from the object.

Tips

Inner shadows require the object to have a Fill. Lines and unfilled shapes cannot display inner shadows.

Tips

Newly drawn objects never start with an inner shadow, even if you left the tool's inner shadow switched on — turn it on per object after drawing. The outer shadow defaults to black at 70% opacity, blur 8, offset 8 left and 8 up; the inner shadow defaults to 30% gray, blur 6, offset 6 and 6.

Reflection

Tick the reflection checkbox to add a mirror reflection below the object, and click the Reflection button to open its settings panel:

  • Enable Reflection: Turns the effect on inside the panel.
  • Strength: The intensity of the reflection (10–200).
  • Distance: The gap between the object and its reflection. A negative value tucks the reflection under the object.

Click OK to apply or Cancel to discard.

Tips

  • Strength scales opacity, not size. Anything above 100% only makes the reflection more opaque; the reflection never grows taller than the object.
  • The Reflection panel is a modal dialog that applies to one object at a time, even if several are selected.
  • A reflection drawn with the object's own shadow enabled suppresses that shadow, so the two effects don't stack.

Copy and Paste Drawing Style

To give an object the same look as another one:

  1. Select the source object and press ⌘C to copy it (the copy also stores its drawing style).
  2. Select the target object or objects.
  3. Choose Edit > Paste Drawing Style (⇧⌘V) to apply the copied colors, line, fill, shadow, and other attributes.

Tips

  • Only the focused object contributes its style, even when several are selected, and nothing is stored while a rubber-band selection is in progress.
  • Groups are expanded, so the style lands on each visible child.
  • Not copied: Line Cap, Corner Radius, Reflection, and — for a text object with mixed formatting — the font and style attributes. Everything else, including gradients, patterns, shadows, and outlines, comes across.
  • Paste is class-checked: a shape's attributes won't stick to text or an image.
