Manage Layers and Objects

You can manage layers and objects using the Layers Panel or the Object menu.

Select

Use the Select and Move tool to click objects on the canvas, or select them directly in the Layers panel.

  • Hold Command or Shift to select multiple items.
  • Choose Edit > Select All Objects to select everything on the canvas.

Rename

Double-click an item's name in the Layers panel to rename it, or choose Object > Rename.

Delete

To delete selected items:

  • Press the Delete key.
  • Choose Edit > Delete.
  • Click the Delete button at the bottom of the Layers panel.
  • Drag them out of the Layers panel.

Duplicate

Choose Edit > Copy then Edit > Paste, or use standard keyboard shortcuts (Command + C, Command + V).

Adjust Opacity

Choose Object > Adjust Opacity… to change the transparency of selected items.

Transform

Choose Object > Rotate and Resize… to rotate or resize selected items.

Flip

Choose Object > Flip Horizontally or Flip Vertically.

Apply Effects

Choose Object > Apply Effect to add filters such as Blur, Sharpen, Crystallize, Pixellate, and more.

Remove Background

Choose Object > Remove Background to automatically detect and remove the background of the selected image layer using AI.

Important

Requires macOS 14 (Sonoma) or later.

Tips

This command applies only to the selected layer. To remove the background of the entire document, use Image > Remove Background.

Arrange

Change the stacking order of layers:

  • Drag and drop items in the Layers panel.
  • Use the arrange buttons at the bottom of the Layers panel.
  • Choose Object > Bring Forward, Send Backward, Bring to Front, or Send to Back.

Group and Ungroup

Combine multiple objects into a single group:

  • Choose Object > Group Selected Objects or Ungroup Selected Groups.
  • Drag and drop items into or out of a group folder in the Layers panel.

Lock and Unlock

Lock objects to prevent accidental selection or modification. Click the lock icon next to an item in the Layers panel, or choose Object > Lock All Objects / Unlock All Objects.

Align

Choose Object > Align to align multiple selected objects (e.g., Left, Center, Right).

Distribute

Choose Object > Distribute to evenly space multiple selected objects.

Merge All Objects

Choose Object > Merge All Objects to flatten all layers into a single image layer.
